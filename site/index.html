wayhouse

A game-agnostic reverse proxy for game servers, written in Rust.

One entry point in front of arbitrary game servers. It forwards TCP and UDP traffic to backend instances without knowing the game's protocol, hides backend IPs so the proxy is the only DDoS-exposed point, and can run as a highly available fleet.
